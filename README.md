# สมุดงาน (yok)

เว็บช่วยงานส่วนตัว ใช้คนเดียวบนเครื่องนี้

- **การ์ดงาน**: จดงานที่ทำไปแล้วและงานที่ยังค้าง มีหัวข้อ รายละเอียด วันที่ สถานะ ความสำคัญ เวลาที่ใช้ และแท็ก
- **สต๊อกสินค้า**: นำเข้ารายงานสต๊อก (.xlsx .xls .csv .pdf) ตรวจยอด แล้ว Export เป็นแบบ "สต๊อกสินค้าออฟฟิศ" ได้ทั้ง Excel, CSV และ PDF
- **สรุปยอดรายวัน**: วางใบเสร็จ (PDF) พร้อมสลิปโอนเงินของลูกค้า ระบบรวมยอดขายแยกวัน และ Export สรุปของแต่ละวันได้ทั้ง Excel, CSV และ PDF
- **ติดตามสินค้า**: วางใบโอนสินค้า (PDF) ระบบรวมไว้ใต้ชื่อสาขา ใส่เลขพัสดุข้างชื่อสาขา แล้วเช็กสถานะจาก J&T Tracking API

## เริ่มใช้งาน

**วิธีง่ายที่สุด:** ดับเบิลคลิก `เปิดสมุดงาน.bat` ระบบจะสร้างหน้าเว็บ เปิดเซิร์ฟเวอร์ แล้วเปิดเบราว์เซอร์ไปที่ http://localhost:3001 ให้เอง (ครั้งแรกจะติดตั้งแพ็กเกจก่อน) ปิดหน้าต่างสีดำเมื่อต้องการปิดเซิร์ฟเวอร์ ถ้าเซิร์ฟเวอร์เปิดอยู่แล้ว ดับเบิลคลิกอีกครั้งจะแค่เปิดเบราว์เซอร์

**สำหรับแก้โค้ด:**

ต้องมี Node.js 22.13 ขึ้นไป (เครื่องนี้มี 24)

```powershell
cd F:\yok
npm install      # ครั้งแรกครั้งเดียว
npm run dev      # เปิด http://localhost:5173
```

ระหว่างพัฒนา `npm run dev` จะรันสองส่วนพร้อมกัน:

| ส่วน | ที่อยู่ | ไฟล์ |
|---|---|---|
| หน้าเว็บ (React + Tailwind ผ่าน Vite) | http://localhost:5173 | `client/` |
| API (Express) | http://localhost:3001 | `server/` |

ใช้งานแบบไม่พัฒนาต่อ: `npm start` จะ build หน้าเว็บแล้วเปิดทุกอย่างที่ http://localhost:3001

## ข้อมูลเก็บที่ไหน

ข้อมูลอยู่ในไฟล์ `data/yok.db` (SQLite ที่มากับ Node) ส่วนไฟล์ใบเสร็จและสลิปอยู่ใน `data/files/` สำรองข้อมูลได้ด้วยการคัดลอกโฟลเดอร์ `data` ตอนปิดโปรแกรม

## ไฟล์ที่นำเข้าได้

รายงาน "รายงานสต็อกสินค้า (รวมตามรหัสสินค้า)" ที่มีหัวตาราง

`ยี่ห้อ, รุ่น, ความจุ, ประเภทสินค้า, ประเภทสต๊อก, รหัสสินค้า, สี, Supplier, จำนวน, ราคาทุน, ราคาขาย, ราคาส่ง`

- แถวที่เว้นยี่ห้อ รุ่น และรหัสสินค้าไว้ นับเป็นรุ่นเดียวกับแถวบน
- ประเภทสต๊อก "มือสอง" = มือ 2 อย่างอื่น ("เครื่องใหม่") = มือ 1
- ราคาขาย 0.00 ถือว่ายังไม่ตั้งราคา
- CSV อ่านได้ทั้ง UTF-8 และภาษาไทยแบบ Windows (TIS-620)
- PDF ต้องเป็น PDF ที่มีตัวหนังสือ (ส่งออกจากโปรแกรม) ไม่ใช่ภาพสแกน ตัวอักษรไทยบางตัวใน PDF อาจเพี้ยนตามฟอนต์ของไฟล์ ถ้ามีไฟล์ Excel หรือ CSV ให้ใช้แบบนั้นจะแม่นที่สุด

## Export

รวมจำนวนตาม **รหัสสินค้า + สี** (ไม่ดูชื่อรุ่น เพราะระบบหน้าร้านอาจตั้งชื่อรุ่นเดียวกันต่างกัน) และส่งออกตามตัวกรองที่เลือกอยู่บนหน้าจอ

ชื่อไฟล์และหัวรายงานใช้สาขาจากบรรทัดบนสุดของรายงาน (เช่น "สต๊อกสินค้าออฟฟิศ") ถ้ารายงานมีหลายสาขาจะเป็น "สต๊อกสินค้ารวมหลายสาขา" และวันที่คือ**วันที่นำเข้าไฟล์นั้น** ไม่ใช่วันที่กดส่งออก

- คอลัมน์: ยี่ห้อ รหัสสินค้า รุ่นสินค้า ความจุ ประเภท (มือ 1/มือ 2) สี จำนวน ราคาขายปลีก ราคาขายส่ง หมายเหตุ
- **ไม่มีราคาทุน**ในไฟล์ส่งออก (ราคาทุนดูได้บนหน้าเว็บเท่านั้น)
- ถ้าไม่มีราคาส่ง จะเขียนว่า **ขายส่งตามEIMI**
- สินค้าประเภท **สายชาร์จ/อะแดปเตอร์** แยกเป็นตารางที่สองต่อท้ายตารางเครื่อง แต่ละตารางมียอดรวมของตัวเอง ยอดด้านบนสุด (มือ 1 / มือ 2 / รวมทั้งหมด) นับรวมทุกอย่าง

รูปแบบไฟล์:

- **Excel**: 2 ชีต
  - "สต๊อกสินค้า": ตารางเครื่อง แล้วตามด้วยตารางสายชาร์จ/อะแดปเตอร์
  - "สรุปตามรุ่น": มือ 1 / มือ 2 / รวม ต่อรุ่น แบบเดียวกับไฟล์สต๊อกสินค้าออฟฟิศ
- **CSV**: เหมือนชีตแรก เปิดใน Excel แล้วภาษาไทยไม่เพี้ยน
- **PDF**: เปิดหน้าพิมพ์ของเบราว์เซอร์ ให้เลือก "บันทึกเป็น PDF"

ถ้ารหัสสินค้าเดียวกันมีหลายราคา จะแสดงราคาของเครื่องส่วนใหญ่ และเขียนราคาอื่นไว้ในหมายเหตุ

### เลข IMEI

วางไฟล์ **รายงานสินค้าราคาขายปลีกและขายส่ง** (หัวตาราง `รุ่น / IMEI, รหัสสินค้า, ประเภทสต๊อก, สาขา, ราคาขายปลีก, ราคาขายส่ง, หมายเหตุ`) พร้อมรายงานสต๊อก หรือวางทีหลังก็ได้ (จะแนบกับไฟล์สต๊อกที่เปิดอยู่ วางใหม่จะแทนรายการเดิม)

- จับคู่ IMEI กับสต๊อกตาม **รหัสสินค้า** (รหัสเดียวมีหลายสี ใช้สีในชื่อรุ่นช่วยแยก) แถบ IMEI ใต้ยอดรวมจะบอกว่าจำนวนตรงกับสต๊อกทุกรหัสไหม ถ้าไม่ตรงกดดูได้ว่ารหัสไหน
- กดเปิดแถวสินค้าเพื่อดู IMEI ทุกเครื่อง ค้นหาด้วยเลข IMEI ได้ในช่องค้นหา
- ไฟล์ส่งออกมีชีตที่ 3 **รายการ IMEI**: 1 แถวต่อ 1 เครื่อง (รุ่นสินค้า, IMEI / Serial, รหัสสินค้า, ประเภท, ราคาขายปลีก, ราคาขายส่ง, หมายเหตุ) มือ 2 ใช้ราคาส่งตาม IMEI ของเครื่องนั้น CSV และ PDF มีส่วนนี้ต่อท้ายเช่นกัน

## สรุปยอดรายวัน

1. **เพิ่มบิล**: ลากใบเสร็จ PDF 1 ใบพร้อมรูปสลิปของบิลนั้นมาวางพร้อมกัน (หรือกด "เพิ่มบิล" แล้วเลือกทั้งสองไฟล์) ระบบอ่านจากใบเสร็จ:
   เลขที่ใบเสร็จ วันที่ ชื่อผู้ซื้อ รายการสินค้า (จำนวน ราคา ส่วนลด จำนวนเงิน และ IMEI ถ้ามี) ส่วนลด และยอดสุทธิ
   - วางสลิปอย่างเดียว จะแนบกับบิลล่าสุดที่ยังไม่มีสลิป ลากรูปไปวางบนแถวของบิลไหนก็แนบกับบิลนั้น หรือกดปุ่มแนบสลิปที่แถว
   - บิลเดียวแนบได้หลายสลิป (ลูกค้าแบ่งโอน) สลิปเป็นรูป .jpg .png .webp .heic หรือ PDF ก็ได้ ใส่ยอดในสลิปเองได้ ระบบจะเทียบกับยอดสุทธิให้
   - เลขที่ใบเสร็จซ้ำจะไม่เข้าซ้ำ
2. **ตรวจ**: บิลที่อ่านได้ไม่ครบขึ้น "ตรวจข้อมูล" กดเปิดบิลจะเห็นแบบฟอร์มให้แก้ทุกช่อง บิลที่ยังไม่มีสลิปขึ้น "ยังไม่มีสลิป"
   ไม่มีไฟล์ใบเสร็จก็ "กรอกเอง" ได้
3. **รายวัน**: บิลเรียงตามลำดับที่เพิ่มเข้ามา แยกกลุ่มตามวันที่ในใบเสร็จ วันล่าสุดอยู่บน กดหัววันเพื่อย่อ/ขยาย (จำไว้ในเครื่องนี้)

ส่วนอ่านใบเสร็จไม่ได้ผูกกับหน้าตาเดียว หาช่องจากชื่อ (ไทยหรืออังกฤษ เช่น เลขที่ใบเสร็จ/Receipt No., ชื่อผู้ซื้อ/Customer Name, ส่วนลด/Discount, ยอดสุทธิ/Grand Total/รวมทั้งสิ้น) และหาตารางสินค้าจากแถวหัวตาราง วรรณยุกต์ที่เพี้ยนใน PDF (เช่น "ผู้ซื่อ") ก็ยังหาเจอ วันที่อ่านได้ทั้ง 26/11/2569, 26 พ.ย. 2569, 26 พฤศจิกายน 2569 และ 26 Nov 2026 ส่วนลดที่พิมพ์เป็น -500.00 หรือ (500.00) นับเป็นส่วนลด 500

ตัวเลขในแบบฟอร์มพิมพ์มีลูกน้ำได้ (เช่น 26,180) ถ้าพิมพ์สิ่งที่ไม่ใช่ตัวเลข ระบบจะบอกว่าช่องไหนผิดและไม่บันทึก

**Export** ปุ่มอยู่ที่หัวของแต่ละวัน
- **Excel** 2 ชีต
  - "สรุปยอดขาย": ยอดรวมของวัน (จำนวนบิล จำนวนชิ้น ส่วนลดรวม ยอดสุทธิรวม) แล้วทุกบิลพร้อมรายการสินค้า ส่วนลดท้ายบิลเป็นบรรทัดแยก ยอดในคอลัมน์จำนวนเงินจึงรวมได้เท่ากับยอดสุทธิ
  - "สรุปตามสินค้า": ขายอะไรไปกี่ชิ้น เป็นเงินเท่าไร เรียงจากยอดมากไปน้อย
- **CSV**: เหมือนชีตแรก
- **PDF**: เปิดหน้าพิมพ์ของเบราว์เซอร์ ให้เลือก "บันทึกเป็น PDF"

ไฟล์ใบเสร็จและสลิปเก็บไว้ที่ `data/files/` (สำรองพร้อมกับ `data/yok.db`) ลบบิลแล้วไฟล์ของบิลนั้นจะถูกลบด้วย

## ติดตามสินค้า

1. **นำเข้าใบ Inv**: ลาก PDF "ใบโอนสินค้าออกระหว่างสาขา" มาวาง (หลายไฟล์ หรือ PDF เดียวหลายใบก็ได้) ระบบอ่าน
   Customer No., Customer Name, พนักงานขาย (Salesman Code), เลขอ้างอิง (Reference No.), Inv. No., วันที่และเวลา และสินค้าทุกชิ้นพร้อม IMEI
   ใบที่มีอยู่แล้วจะข้าม
2. **รอเลขพัสดุ**: ใบที่ยังไม่มีเลขพัสดุรวมอยู่ใต้ชื่อสาขา (Customer Name) ช่องเลขพัสดุอยู่ข้างชื่อสาขา
   ยิงหรือพิมพ์เลขแล้วกด Enter ใบทั้งหมดของสาขานั้นจะรวมเป็น **1 รอบส่ง** (หลายกล่องใส่หลายเลขคั่นด้วยเว้นวรรค หรือกด "เพิ่ม" ทีหลัง)
   ใบใหม่ของสาขาเดิมที่เข้ามาทีหลังจะเริ่มกลุ่มใหม่
3. **ดูสถานะที่เว็บ J&T**: กด "เปิดเว็บ J&T" (ทุกเลขที่ยังไม่ถึง) หรือ "ดูใน J&T" ที่รอบส่ง หรือกดที่เลขพัสดุ
   ระบบเปิด https://www.jtexpress.co.th/service/track พร้อมกรอกเลขให้ (ใช้ลิงก์ `?waybillNo=เลข1,เลข2`) เว็บ J&T รับครั้งละไม่เกิน 10 เลข
   ถ้ามีมากกว่านั้นจะแบ่งเป็นปุ่ม "ชุด 1", "ชุด 2" เว็บ J&T จะให้ **เลื่อนจิ๊กซอว์ยืนยันตัวตน** ก่อนแสดงผล ขั้นนี้ต้องทำเอง
4. **บันทึกสถานะ**: กลับมาเลือกสถานะข้างเลขพัสดุ (ยังไม่ได้ดู / กำลังส่ง / ถึงแล้ว / มีปัญหา / ตีกลับ) หรือกด "ถึงครบแล้ว" ทั้งรอบ
   รอบที่ทุกกล่องถึงแล้วจะย้ายไปแท็บ "ถึงแล้ว" ส่งผิด กด "ยกเลิกรอบส่ง" ใบจะกลับไปรอเลขพัสดุ หรือกด "เอาออก" ทีละใบ

ไม่ใช้ API ของ J&T หรือ 17TRACK และไม่มี key ให้เก็บ ระบบไม่เข้าเว็บ J&T เองเบื้องหลัง เพราะเว็บ J&T มีจิ๊กซอว์กันบอท
